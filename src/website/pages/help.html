Help

Add Link Embedder to your server, share a public link, and manage your reposts from Discord.

Install and set up

Use the Add to Discord button on the homepage. You need permission to install apps in your server.

In each channel where you want previews, allow View Channel, Send Messages, Embed Links, Read Message History, Manage Messages, and Manage Webhooks. Threads also require Send Messages in Threads, with View Channel and Manage Webhooks on the parent channel. Administrator is not required.

Use /permissions to privately check the bot’s permissions in the current channel or another channel you can manage. For a grouped server summary, use /permissions scope:server. Add page:2 to see the next page. Only channels you can view and manage are included, with coverage limits stated in the report. The command does not change roles or channel settings.

Share a link

Post a supported public HTTPS link in a text channel, voice-channel text chat, or active public thread under a text, forum, or media channel. Your surrounding text stays with the card. Known tracking parameters are removed. Required content IDs and playback parameters stay intact.

Same-channel and same-thread replies show a small reply-context line above your text: an italic “Click to see message” link to the exact reply target, with a bold author mention when the human author is verified. Reply context never copies the target’s text. The author mention opens their profile and permits a notification on initial posting. Edits and NSFW updates do not notify them again. Inaccessible references stay untouched. This is linked context, not a native Discord reply.

Wrap a link in angle brackets, spoiler markup, or code to suppress its preview. Attachments, polls, pinned messages, thread starters, DMs, and existing messages are not replaced. Private, archived, locked, and announcement threads are excluded.

Manage your repost

Use ⋯ beside a new card’s title, or Apps → Manage Post, to open private controls. Original authors can edit or delete tracked reposts and use Remove spoiler to uncover marked gallery media. Anyone with channel access can mark media NSFW. Older, untracked posts need a moderator.

If a preview is missing

  • Check the bot’s channel permissions and whether the link is public.
  • Allow a few seconds for the source to respond. Private, expired, or unavailable media cannot always be previewed.
  • Check that the message is new and has no attachments. Replies require an accessible reference in the same channel or supported thread. Thread starters and inaccessible, private, archived, locked, or announcement threads are left alone.
  • If the problem continues, contact us with the public link and a description of what happened. Do not send passwords, tokens, or private links.
