LINK EMBEDDER FOR DISCORD

Clean links.
Better previews.

Share supported public links as Discord cards with text and media. Known tracking parameters are removed.

Easy install

Grants full server permissions

Requests Administrator and bypasses channel permission restrictions.

Limited-permissions install

Requests only the permissions the bot needs. Private or restricted channels may need extra setup.

Setup guide

Supported sites

Cards for Amazon, Bluesky, Facebook, Instagram, Pinterest, Reddit, Snapchat, Threads, TikTok, Twitter, and UpScrolled.

Supported formats and media vary by site. See supported links and limits.

Consistent cards

Text and media use the same layout across supported sites.

Cleaner links

Known tracking parameters are removed. Required content IDs and playback parameters stay intact.

Post controls

Use ⋯ in the top-right corner of the card to open private controls, or use Discord’s Apps menu.
