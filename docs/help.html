Help & channel access

Link Embedder is online in a limited alpha test channel. It handles new supported public links there; other channels and servers are currently excluded. Features may change or fail during testing.

Share a supported link

Use the full canonical HTTPS post URL. Short links, deleted/private posts, login-only or age-gated content and unsupported routes can fail. YouTube and Amazon use native Discord previews. Other platforms may show a basic card or an approved helper preview. Media playback is not guaranteed.

Control previews

Wrap a link in angle brackets, spoiler markup or code to prevent its preview. Message-level embed suppression is also respected. Original messages stay unchanged in normal reply mode. The configured alpha channel uses author-style reposts: eligible originals are replaced only after a replacement is sent. Replacements display Discord’s APP badge and can be managed by the original author through Apps → Manage my post when a saved ownership record exists. Old previews are not synchronized with source edits or deletions; ask a moderator to remove them if needed.

For server administrators

Open Edit Channel → Permissions, choose the Link Embedder role or member, and allow View Channel, Send Messages and Embed Links. For threads and forum posts, also allow Send Messages in Threads on the parent channel. Check category inheritance and role/member denies. Administrator is not required.

During this alpha, only the explicitly configured test channel is enabled, even if other channels grant permission. Outside the pilot configuration, current and newly created channels can work when permissions allow. There is no per-server settings screen or production channel list. Private threads require normal membership access; the bot never forces a join. Archived and locked threads are skipped. The bot cannot grant itself access or guarantee access everywhere.

No reply?

First check the host console: the status shown on this site is a manual update and can become outdated. During alpha, confirm the message is in the configured test channel. Then check permissions and link format. Rate limits allow up to three links per message, one reply per channel per three seconds, and twenty replies per server per minute. Excess messages are skipped, not queued. Provider failures and delayed Discord embeds can affect results.

Public content and privacy

Channel age labels do not classify links. Use ordinary non-explicit public content; no automated explicit-content filter is promised. Read the privacy disclosure before using external preview helpers.

Contact

Use the contact form for support, bug reports, and privacy or deletion requests. Ask a server administrator to remove an existing bot response or restrict access. Do not post private URLs, credentials or personal information in public reports.

Add Link Embedder to Discord

Manage your repost

Go to the repost, open its options, choose Apps, choose Link Embedder if shown, then Manage my post. Only the original poster receives the private Delete post · Mark NSFW · Dismiss menu. Dismiss does not remove access: repeat those steps any time. Mark NSFW covers custom-card photos/videos with spoilers; captions and links stay visible. It does not age-restrict anything. Native previews cannot use this media control. Delete post removes the repost permanently and does not restore the original. Only new reposts with saved ownership records can be managed; older posts need a moderator.

Current custom-card support

Custom cards put an available bold post title above the media (Reddit: r/subname: Post title), then the creator. Identical title/caption text is shown once. Custom cards use a platform-colored accent, bold display name with a plain @username when metadata supplies them, media above a plain caption capped at 250 characters, and a platform footer via @Link Embedder. The bot-profile mention does not send a notification. No statistics, dates, author portraits or provider buttons are added. Discord controls gallery width and aspect ratio; vertical videos cannot be forced to fill the card. Unknown author names are not invented.

Instagram, TikTok, Twitter, Bluesky, Reddit, Twitch and Snapchat helpers are approved for the pilot. Their metadata is requested directly with bounded responses and no cookies or redirect following. Medal, Streamable, Imgur and LinkedIn use public first-party metadata only. Media availability is experimental: unavailable metadata produces an honest link card. Facebook, RedNote, UpScrolled and selected Mastodon instances remain limited cards. YouTube, Amazon, iFunny, Vimeo, GIPHY and Tenor retain native previews; mixed messages containing a native platform retain the native/helper route. iFunny returned HTTP 401 in the public metadata check; no bypass is attempted. Imgur albums may show only their published preview image. LinkedIn often requires login. Native availability is controlled by Discord and the source site.
