Help & channel access

Currently offline. Once deployed, Link Embedder handles new supported public links automatically where permissions allow.

Share a supported link

Use the full canonical HTTPS post URL. Short links, deleted/private posts, login-only or age-gated content and unsupported routes can fail. YouTube and Amazon use native Discord previews. Other platforms may show a basic card or an approved helper preview. Media playback is not guaranteed.

Control previews

Wrap a link in angle brackets, spoiler markup or code to prevent its preview. Message-level embed suppression is also respected. Original messages stay unchanged. Old previews are not synchronized with source edits or deletions; ask a moderator to remove them if needed.

For server administrators

Open Edit Channel → Permissions, choose the Link Embedder role or member, and allow View Channel, Send Messages and Embed Links. For threads and forum posts, also allow Send Messages in Threads on the parent channel. Check category inheritance and role/member denies. Administrator is not required.

Current and newly created channels work automatically when permissions allow. There is no per-server settings screen or production channel list. Private threads require normal membership access; the bot never forces a join. Archived and locked threads are skipped. The bot cannot grant itself access or guarantee access everywhere.

No reply?

First check that the service is online—this release is not yet deployed. Then check permissions and link format. Rate limits allow up to three links per message, one reply per channel per three seconds, and twenty replies per server per minute. Excess messages are skipped, not queued. Provider failures and delayed Discord embeds can affect results.

Public content and privacy

Channel age labels do not classify links. Use ordinary non-explicit public content; no automated explicit-content filter is promised. Read the privacy disclosure before using external preview helpers.

Contact

Use the contact form for support, bug reports, and privacy or deletion requests. Ask a server administrator to remove an existing bot response or restrict access. Do not post private URLs, credentials or personal information in public reports.
