How do I use this in the bot?

This editor produces legacy embed drafts. Production custom media cards use Components V2 in src/simple-cards.js and src/instagram-card.js, with colors/logos in src/platform-brands.js. A code change, tests and deployment are required to update the bot.

Custom cards use a platform-colored accent, bold display name with a plain @username when metadata supplies them, media above a plain caption capped at 250 characters, and a platform footer via @Link Embedder. The bot-profile mention does not send a notification. No statistics, dates, author portraits or provider buttons are added. Discord controls gallery width and aspect ratio; vertical videos cannot be forced to fill the card. Unknown author names are not invented. Native players remain controlled by Discord and the original site. This mockup does not reproduce every production layout or play real media.
