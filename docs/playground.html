How do I use this in the bot?

The current basic-card layout is in src/previews.js, inside buildPayload. Export your design and use it as the embed template there. Keep each post’s title and URL dynamic, then test and deploy the change.

Native YouTube videos and third-party media helpers have layouts controlled by Discord and their providers. This editor cannot rearrange their players, fetch private media, or guarantee playback. The bot does not currently fetch images for basic cards.
