3. Permissions and data

Administrators can restrict access using Discord permissions or remove the bot. It does not require Administrator, change permissions or force access. When author-style reposts are enabled and the required channel permissions are granted, it may delete an eligible original only after posting a replacement sent through the bot’s webhook. The replacement uses a webhook with the author’s display name and avatar; original posters can manage newly tracked reposts through Apps → Manage Post; older untracked posts need a moderator. Read the Privacy Policy for transient processing, Discord storage and optional third-party URL sharing.
