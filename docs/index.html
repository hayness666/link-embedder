Installation does not start the bot. It currently runs only in its configured pilot channel. YouTube playback and author-style reposting have been verified there; other media providers remain unverified. This is an install link, not an App Directory listing.

Current support

Implemented helper routes cover Instagram, TikTok, Twitter, Bluesky, Reddit, Twitch clips and public Snapchat links. Helpers require approval before activation. YouTube and Amazon use cleaned native links by default. Facebook, LinkedIn, UpScrolled, RedNote and selected Mastodon instances have experimental basic link cards, not verified media playback.

Contact

Use the contact form for support, bug reports, and privacy or deletion requests. For a Discord message issue, ask your server administrator to remove the bot response or restrict access. Do not post credentials, private URLs or personal data in public reports.
